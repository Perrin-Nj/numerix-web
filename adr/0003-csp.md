# ADR 0003: Content Security Policy

Status: accepted for v0.

`vercel.ts` sets a strict CSP (self only for scripts, styles, images, media, fonts and connections; no framing; no third parties). `script-src` and `style-src` keep `'unsafe-inline'` because Next.js inlines small bootstrap scripts and styles. Next step: nonces through the proxy so `'unsafe-inline'` can go. Remote images and extra API origins are opened only through the `IMAGE_HOSTS` and `CONNECT_ORIGINS` variables.
