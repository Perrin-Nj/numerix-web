# ui

Generic building blocks with no product knowledge: button, card, dialog, sheet, select, switch, tabs, tooltip, progress, skeleton, banner, form field, PIN input, icon, virtual feed, notification center, guided tour. Radix and other libraries are wrapped here and nowhere else.

Rules: every component has a Storybook story, is keyboard and screen reader friendly, honours reduced motion, and takes text from its caller (no copy in this layer).
