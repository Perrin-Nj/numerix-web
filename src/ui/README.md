# ui

Design-system primitives: button, dialog, input, switch, select, tabs, toast center, skeleton, bottom nav, and so on. They know nothing about Numerix and import only `platform`, `shared`, `config`, `i18n`. Radix UI is imported here and nowhere else.

Rules: tokens from `app/globals.css`, three themes, 44 px touch targets, keyboard and screen-reader support, stories for every primitive.
